# Izak Hyllested Portfolio

Fresh editorial redesign with animated intro screen.

## Features

- Black animated splash screen with centered white "Izak Hyllested"
- Splash stays for approximately 2.8 seconds and animates in/out
- Swiss/editorial minimalist visual style
- Portfolio home page
- Projects page
- No package-lock.json
- No TypeScript
- No import aliases
- Vercel-safe config

## Vercel

Leave settings on default, or use:

- Install Command: `npm install --no-package-lock --no-audit --no-fund`
- Build Command: `npm run build`
- Output Directory: leave empty

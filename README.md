# Izak Portfolio

Clean Next.js portfolio app.

## Vercel settings

Leave build settings as default, or use:

- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: leave empty / Next.js default

## Important

Do not upload `node_modules`.
Do not use an old `package-lock.json`.
The repository root should directly contain:

- app/
- components/
- data/
- package.json
- tsconfig.json
- next.config.mjs
